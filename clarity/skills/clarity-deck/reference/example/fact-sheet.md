## Conflicts for the recruiter to confirm

1. **Leadership titles.** Website: Melissa Holden, Michael Bruning, Jonathan Birbeck are VPs.
   Enrichment data has Birbeck as "Associate Director". Deck uses the website.
2. **Headcount.** Intake note: 42 to 43 in Feb 2026. Website today: 57. Deck shows both as growth.
3. **Alex Woodhead's title in Loxo** is "Senior Advisor, Advanced Air Mobility Institute". Stale; worth fixing in Loxo.
4. **CoRecruit mixes up the company names.** The second 2 Feb summary and the 9 Jun note say
   "Clarity R2R" where they mean Apera. The skill must read these notes with that in mind.
5. **Values.** The website says Apera has five external values but lists four. Deck shows the four.
6. **Is the role still open?** The 9 Jun note records "Amy" accepting the role, and the website now
   lists Ami Noble-Newton as COO. If that is this hire, the deck is a test only.
